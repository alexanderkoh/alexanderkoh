I'm a designer and developer in New York with a background in program management, so I like owning the whole arc of a product: the idea, the interface, the code and the launch. I run **Bastian's Creative Studio**, and my work moves between product design, AI agents, games and smart contracts.

### Now building

- **Hierro**: text to game-ready 3D models (GLB), built on Blender
- **Stampbase** and **Stellar Passport**: a participation and identity layer for web3 communities
- **Studio**: a portfolio OS and agent harness built around one person's decisions
- **3D Incremental Game**: currently being built in stealth

<sub>Most of these are still private.</sub>
